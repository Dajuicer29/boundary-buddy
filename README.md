# Boundary Buddy 🔥

**Transform your boundaries into unbreakable habits**

Track and strengthen your personal boundaries with science-backed habit tracking. Join thousands building better boundaries in family, work, relationships, and health.

## ✨ Features

- 🔥 **Streak Tracking** - Build consistent habits day by day
- 📊 **Advanced Analytics** - Success rates, category breakdown, best streaks
- 📂 **Smart Categories** - Track boundaries in Family, Work, Personal, Friends, Romantic, Health, Social
- 💬 **Reflection Notes** - Document what happened and how you felt
- 🏆 **Achievements** - Unlock badges and milestones
- 📱 **Mobile-First Design** - Works perfectly on phone, tablet, desktop
- 💾 **Offline-First** - All data saved locally in your browser
- 📢 **Social Sharing** - Share progress on Twitter, Facebook, WhatsApp

## 🚀 Quick Start

### For Users
1. Open `index.html` in your browser
2. Click "Yes" or "No" for today's boundaries
3. Select a category (Family, Work, etc.)
4. Add a note about what happened
5. Watch your streak grow! 🔥

### For Developers

```bash
# Clone the repo
git clone https://github.com/yourusername/boundary-buddy.git
cd boundary-buddy

# Run locally
npm run dev
# Visit http://localhost:8080

# Deploy to Vercel
npm run deploy
```
